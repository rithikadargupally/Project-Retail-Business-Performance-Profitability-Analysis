# Project-Retail-Business-Performance-Profitability-Analysis


## Project Overview

This project analyzes retail transaction data to understand sales performance, profitability, and product behavior. The goal is to identify profitable categories, loss-making products, and provide business insights using data analysis and visualization.

## Objective

- Analyze retail sales and profit trends
- Identify top-performing products and categories
- Find loss-making products
- Calculate profit margins
- Support data-driven business decisions

## Tools Used

- Python (Pandas) - Data cleaning and exploratory analysis
- SQL (MySQL Workbench) - Data querying and calculations
- Power BI - Dashboard creation and visualization

## Dataset

Dataset used:

**Retail_Cleaned_Data.csv**

The dataset contains:
- Order details
- Product information
- Category and sub-category
- Sales
- Quantity
- Profit
- Region

## Project Workflow

### 1. Data Cleaning (Python)

- Imported dataset using Pandas
- Checked missing values
- Cleaned data for analysis
- Prepared dataset for visualization

### 2. Data Analysis

Performed analysis on:

- Total Sales
- Total Profit
- Profit Margin
- Sales by Category
- Profit by Category
- Top 10 Products by Sales
- Top 10 Products by Profit
- Loss-making Products

### 3. SQL Analysis

Created SQL database and performed queries for:

- Data validation
- Category-wise sales and profit analysis
- Profit margin calculation
- Product profitability analysis
- Finding products with negative profit

### 4. Dashboard

Created an interactive Power BI dashboard with:

- KPI Cards:
  - Total Sales
  - Total Profit
  - Total Quantity
  - Profit Margin %

- Visualizations:
  - Sales by Category
  - Profit by Category
  - Top Products by Sales
  - Top Products by Profit
  - Loss-making Products

## Key Insights

- Technology category contributes the highest profit.
- Some products generate losses and need business review.
- High sales products are not always highly profitable.
- Product-level analysis helps improve inventory and pricing decisions.

## Conclusion

This project combines Python, SQL, and Power BI to analyze retail business performance. The dashboard helps identify profitable areas, reduce losses, and make better business decisions using data.
